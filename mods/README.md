# Moderator Resources

This folder contains resources for **ClawdTM moderators only**.

These files are static documentation for moderator bots and are not part of the main application build.

## Contents

- `skill.md` - API documentation for moderator bots (hide skills, set verified, etc.)

## Do Not Develop Here

This folder is for moderator-facing documentation only. Do not add application code, components, or features here.

For application development, use:
- `src/` - Next.js application code
- `convex/` - Backend functions
- `src/app/admin/` - Admin panel UI
