ClawdTM

A vetted skill directory for OpenClaw agents.

ClawdTM is no longer running. The catalog sync, security scanner, and public API were decommissioned in August 2026, and the backend has been shut down.

Nothing here is coming back online, but nothing is lost either — the full source is preserved on GitHub under an MIT licence, and anyone is free to fork it and stand up their own.
